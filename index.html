How it is stored

KRXFILE2 layout

  1. magic “KRXFILE2” · 8 bytes
  2. version 1 byte · cipher & KDF ids
  3. cost 4-byte iteration count
  4. salt / iv 16 + 12 bytes
  5. payload AES-GCM(name, size, bytes)
Bytes 0–43 are authenticated as additional data. Changing the iteration count or salt breaks the tag instead of producing garbage.
Files are read into the tab's memory before sealing. Very large files (multi-gigabyte) may exhaust it; chunked streaming is on the roadmap.
